# Monte Carlo Simulation in Comparison to Black-Scholes Model

The Black-Scholes model utilizes the concept of Brownian motion to calculate the expected future value of a stock price. Alternatively, we can calculate this expected value using monte carlo simulation; simulating a large number of price paths and averaging them. By doing so, we can observe the convergence of the monte carlo method to the true Black-Scholes value over an increasing number of simulations.
